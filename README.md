
# BooksCollector — юнит-тесты

Проект содержит юнит-тесты для класса `BooksCollector`. Тесты написаны с помощью `pytest` и покрывают все публичные методы класса.

## Реализованные тесты

- `test_add_new_book_valid_names`: проверка добавления книг с корректными названиями (включая граничные значения длины).
- `test_add_new_book_invalid_names`: проверка отклонения книг с пустыми или слишком длинными названиями.
- `test_add_new_book_no_duplicates`: проверка, что одну и ту же книгу нельзя добавить дважды.
- `test_set_book_genre_valid`: установка допустимого жанра для существующей книги.
- `test_set_book_genre_book_not_exists`: попытка установить жанр для несуществующей книги (без изменений).
- `test_set_book_genre_invalid_genre`: попытка установить недопустимый жанр (жанр не сохраняется).
- `test_get_books_with_specific_genre`: получение списка книг по жанру (включая случай с несуществующим жанром) — параметризованный тест.
- `test_get_books_for_children`: получение книг, подходящих детям (без возрастного рейтинга).
- `test_favorites_add_and_no_duplicates`: добавление книги в избранное и защита от дубликатов.
- `test_favorites_delete_and_list`: удаление книги из избранного и проверка списка.
- `test_get_books_genre`: возврат полного словаря книг и жанров.

## Запуск тестов

```bash
pytest -v tests.py
